Koopman Lifting for Linear Encrypted Control of Nonlinear Systems: Applications to LQR and MPC

Uta Kawakami, Kenji Sawada

arXiv:2611.25494·eess.SY·Published 2026-11-19

Homomorphic encryption enables control computations to be outsourced to a third-party cloud server without disclosing measurements or controller parameters. Applying existing encrypted linear controllers to nonlinear plants requires a compatible representation of the plant dynamics. This paper presents Homomorphically Encrypted Koopman-Based Control (HEK-Control), which connects nonlinear plants to encrypted linear computations through Koopman lifting. A trusted plant-side client evaluates nonlinear functions of the measured state, and a linear predictor identified in these coordinates supports conventional controller design. The resulting control laws retain the server's encrypted linear operations. We demonstrate the framework using state feedback based on linear quadratic regulation and input-constrained model predictive control. Closed-loop simulations with the Cheon--Kim--Kim--Song encryption scheme show close agreement with unencrypted computations. Additional unencrypted simulations compare regulation under input constraints across a common set of controller designs. For a continuous stirred-tank reactor, Koopman lifting supports regulation at input bounds not handled by the tested controllers designed directly in the original state coordinates. Tests of encrypted computations also show that packing multiple values into each ciphertext reduces computation time and communication volume. These results clarify how existing encrypted linear computations can serve nonlinear plants.
